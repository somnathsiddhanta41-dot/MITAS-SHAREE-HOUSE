# MITA'S SHAREE HOUSE

Premium saree ecommerce experience — **Elegance Woven Into Every Thread.**

## Included
- Responsive React + TypeScript + Vite storefront
- Premium glassmorphism fashion UI
- 20 demo saree products
- Shop, search, filters, collections and product details
- Persistent cart and wishlist using LocalStorage
- Checkout and demo order confirmation
- Customer account and order tracking
- Admin dashboard with products, orders, customers, reviews, coupons, inventory and analytics
- GitHub Pages deployment workflow

This is a demo ecommerce application. Payment interfaces are non-processing demo UI and no real payment credentials should be entered.
